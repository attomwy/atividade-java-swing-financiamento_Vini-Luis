# Simulador de Financiamento de Veículos

Atividade desenvolvida em Java Swing para simular o financiamento de um veículo.

## Requisitos

- Java 11 ou superior

## Como executar

Abra o projeto em uma IDE Java e execute a classe:

`br.edu.univille.App`

## Funcionalidades

- Marca, modelo, ano e valor do veículo
- Seleção entre veículo novo e usado
- Dados extras para veículo usado
- Entrada opcional
- Parcelas de 12, 24, 36, 48 ou 60 meses
- Validação dos campos
- Cálculo do financiamento
- Botão para limpar o formulário

A taxa utilizada no cálculo é de 32%.
